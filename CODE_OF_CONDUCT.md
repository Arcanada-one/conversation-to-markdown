# Code of Conduct

## Our standard

We want this project to be a useful, safe, and welcoming place to collaborate. Be respectful, patient, and specific. Discuss ideas and code without attacking people. Make room for different experience levels, backgrounds, and communication styles.

Harassment, threats, discriminatory language, sexualized attention, deliberate intimidation, publication of private information, and sustained disruption are not acceptable. Do not place another person's conversation data, credentials, or identifying information in an issue, pull request, or discussion.

## Enforcement

Maintainers may edit or remove contributions that violate this standard and may temporarily or permanently restrict participation. Enforcement decisions should consider context, impact, previous behavior, and the safety of affected people.

To report conduct privately, use the repository's private vulnerability reporting channel and label the report as a conduct matter. If that channel is unavailable, open an issue asking for a private contact method without including sensitive details.

This policy applies in repository spaces and when someone represents the project elsewhere.
