# Version 1.6.9 closeout — generated-file export repair

Archived on 2026-10-09. The operator reported the correction recorded and requested task closeout, archival, and pushing the remaining work.

## Outcome and scope

Modern ChatGPT generated-file references were omitted because the exporter recognized legacy file buttons and sandbox paths but not the observed modern shapes. The repair recognizes file-reference controls, preserves their names in Markdown, resolves explicit sandbox links from additional directories, and accepts complete modern conversation message inventories when the legacy endpoint is unavailable. Unresolved references and paginated/incomplete inventories remain explicitly incomplete.

Source repair and the release are delivered. Original missing-file recovery was performed locally: the manually retrieved archive passed integrity checks and all 23 manifest-listed payloads passed size and SHA-256 checks. Private conversation content, identifiers, and attachments are intentionally excluded from this public archive.
